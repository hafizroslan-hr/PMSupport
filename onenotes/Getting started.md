# Using the knowledge hub

This is a sample note so the search page has something to find. Delete it from the Manage notes page once your own notes are loaded.

## Exporting notes from OneNote

In the OneNote desktop app choose File → Export, pick Page, Section or Notebook, then pick a format and save. Upload the saved file on the Manage notes page.

Word Document (.docx) gives the best results: headings become separate knowledge entries, and tables, lists and screenshots are kept.

Single File Web Page (.mht) and PDF (.pdf) also work. PDF keeps text only, one entry per page.

## Uploading a native .one section file

OneNote section files (.one) can be uploaded directly, but the format is proprietary. Only the plain text is recovered, without formatting, screenshots or page titles, and a little noise can slip in. If the result looks poor, export the section as Word (.docx) instead.

## Getting better search results

Use Heading 1, Heading 2 and Heading 3 styles in your notes. Each heading becomes its own entry, so a search lands on the exact fix instead of a whole notebook.

Put the error message, transaction code or system name in the heading or the first line, because title matches rank highest.

## Updating or replacing a note

Upload a file with the same name into the same notebook folder. It replaces the old version and the index is rebuilt immediately.
